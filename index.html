Git Cheat Sheet

Je snelle gids om je code op te slaan, te uploaden en op een andere laptop te gebruiken.

Onthoud: Git bewaart je wijzigingen lokaal. Met git push stuur je ze naar GitHub. Met git pull haal je de nieuwste wijzigingen op.

01 — Dagelijks gebruik

Bekijk je wijzigingen

Controleer welke bestanden veranderd zijn.

git status

Toont gewijzigde, nieuwe en niet-opgeslagen bestanden.

Voeg bestanden toe

Kies welke wijzigingen je wilt bewaren.

git add .

Voegt alle wijzigingen in de huidige repository toe.

Sla wijzigingen op

Maak een checkpoint in je Git-geschiedenis.

git commit -m "Beschrijving van wijziging"

Gebruik een korte, duidelijke beschrijving.

Upload naar GitHub

Stuur je commits naar de online repository.

git push

Uploadt je lokale commits naar GitHub.

Haal wijzigingen op

Doe dit bijvoorbeeld voordat je verder werkt.

git pull

Haalt wijzigingen van de gekoppelde branch op.

Bekijk je branches

Bekijk op welke branch je werkt.

git branch

Toont je lokale branches. De huidige branch heeft een sterretje.

02 — Eenmalige instellingen

Maak een repository

Gebruik dit in je projectmap als Git nog niet is ingesteld.

git init

Initialiseert een lokale Git-repository.

Stel de hoofdbranch in

git branch -M main

Hernoemt je huidige branch naar main.

Koppel GitHub

git remote add origin https://github.com/JOUW-GEBRUIKERSNAAM/JOUW-REPO.git

Vervang de URL door die van jouw GitHub-repository.

Eerste upload

git push -u origin main

Uploadt main en stelt de standaard upstream in.

03 — Je project op een andere laptop

Clone je repository

git clone https://github.com/JOUW-GEBRUIKERSNAAM/JOUW-REPO.git

Downloadt de repository en maakt een projectmap aan.

Ga naar je projectmap

cd JOUW-REPO

Voer Git-commando's uit binnen de repository.

04 — Mijn vaste workflow

Gebruik deze volgorde wanneer je klaar bent met werken:

git status
git add .
git commit -m "Beschrijf je wijzigingen"
git push

Werk je op een andere laptop? Doe eerst git pull voordat je begint. Zo vermijd je conflicten met wijzigingen die al op GitHub staan.

05 — Handige extra's

Bekijk recente commits

git log --oneline

Toont een beknopt overzicht van je geschiedenis.

Bekijk de GitHub-koppeling

git remote -v

Toont de URL's voor ophalen en uploaden.

Bekijk welke bestanden Git volgt

git ls-files

Toont de bestanden die momenteel door Git worden gevolgd.

Bekijk verschillen

git diff

Toont niet-gestagede wijzigingen in gevolgde bestanden.
